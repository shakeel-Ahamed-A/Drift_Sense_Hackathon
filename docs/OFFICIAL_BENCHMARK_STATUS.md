# Drift-Sense Official-Source Benchmark Report

## Benchmark status

**Status: BLOCKED BY OFFICIAL DATA AVAILABILITY, NOT BY THE LOCAL IMPLEMENTATION.**

The requested benchmark cannot honestly be reported as an "official test-set benchmark" from the public Hugging Face Space at this time.

The important distinction is:

1. The Hugging Face Space is a **synthetic-data generator**, not a published fixed benchmark dataset.
2. Its README explicitly states that **no dataset is provided by the hackathon** and instructs users to generate a dataset split locally.
3. The hackathon description says the official Phase 2 test set is a **separate set generated by Applied Materials** and that its exact placement/noise parameters are not public.

Therefore there is no public, fixed set of "official Hugging Face-generated pairs" that can be downloaded and benchmarked here in the same sense as a frozen benchmark dataset.

This is materially different from the separate challenge requirement that participants include rotation and scale variation in their own enhanced generator.

## 2. Official benchmark protocol

The official hackathon description states:

- no public dataset is supplied for the Drift-Sense problem;
- teams generate their own synthetic training/self-evaluation data;
- at least 30 randomized pairs are required for self-evaluation;
- Applied Materials will evaluate submissions on a separate Phase 2 test set;
- that test set contains at least 30 randomized pairs across DRAM and FinFET;
- the official test set is noisier than the training examples;
- it includes at least one deliberately difficult highly periodic region.

Therefore a locally generated HF-Space split is **not** equivalent to the hidden official Phase 2 test set.

## 4. Why the exact requested run could not be executed

There are two independent blockers.

### Blocker A — no frozen official pair dataset

The public Space does not publish a fixed benchmark split containing the requested reference/search pairs.

Instead, it provides a generator that creates new pairs from a seed.

Consequently, a statement such as:

> "Hybrid achieved 96% on the official Hugging Face dataset"

would be factually unsupported.

### Blocker B — this execution environment cannot run the Space's generator repository directly

The runtime available for this analysis cannot establish a direct Git/network connection to `huggingface.co` for local package cloning/execution.

The Space itself is exposed as a Streamlit application, and its public web page does not provide a machine-readable image-pair API that can be invoked from this environment.

The source code was nevertheless inspected through the public Hugging Face repository interface, allowing the exact generator protocol and source parameters to be verified.

Use at least 30 samples, preferably 60 to balance the two architecture families.

Recommended:

```bash

    --num-samples 60 \

    --split official_source_eval \
    --output-dir ./output \
```

This is **not the hidden Applied Materials Phase 2 test set**. It is a reproducible benchmark generated by the official public generator.

## 9. Required benchmark acceptance criteria

The benchmark should only be called successful if:

1. every manifest row is processed;
2. no reference/search pair is silently skipped;
3. failed predictions count as failures;
4. ground-truth coordinates are read directly from the official manifest;
5. no test image is used to tune thresholds;
6. the hybrid parameters remain unchanged;
7. results are repeatable for a fixed seed;
8. DRAM and FinFET results are reported separately;
9. latency is measured on the same hardware across methods;
10. any proposed algorithmic change is justified by a reproducible failure.
